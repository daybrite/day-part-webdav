Commands and reproduction notes

Root: cargo test --offline --all-features, cargo clippy --offline --all-features --all-targets -- -D warnings, cargo fmt --all -- --check. Real servers: python3 scripts/capture.py --native. Demo: day launch -t TARGET --script dayscript/demo.yaml, selecting a particular simulator/emulator when several are present. See the demo guide for the browser fixture.

Local Day patches were generated with day patch --local; they and Cargo locks/build outputs are ignored. The installed CLI was stale, so these runs used the current local day/target/debug/day. CI uses Day main until the HTTP method additions are released. Publish is disabled in this initial workflow.

Android’s shared Gradle cache referenced a missing transformed plugin JAR; an isolated GRADLE_USER_HOME=/tmp/day-webdav-gradle successfully packaged the app. Harmony packaging needed the installed hvigor plugin on NODE_PATH and a versioned SDK directory supplied via OHOS_BASE_SDK_HOME. These are local toolchain arrangements, not repository dependencies or weakened validation.

These observations are not DAV failures and have not been hidden by skipping protocol checks.

The walkthrough covers the automatic protocol exercise, provider switching, constrained-network admission, resource browsing and cancellation. It does not interact with every manual control; element coverage is about 15%. Core operations are asserted separately by the protocol exercise and Rust tests. Credentials, production TLS chains, enterprise proxies, power-loss durability and arbitrary hosted-server behavior require further qualification.
